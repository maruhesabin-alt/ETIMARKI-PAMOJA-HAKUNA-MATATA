ETIMARKI PAMOJA HAKUNA MATATA — SITE WEB

Cette archive utilise uniquement des noms de fichiers/dossiers compatibles Windows.

Extraction recommandée :
1. Clic droit sur le fichier ZIP > Propriétés > décocher « Débloquer » si l'option apparaît.
2. Cliquer sur « Extraire tout… ».
3. Ouvrir le dossier ETIMARKI_SITE_FINAL.
4. Ouvrir index.html.

Si Windows affiche encore « Accès refusé au dossier compressé », utiliser WinRAR > Extraire ici,
ou copier le ZIP dans Documents puis l'extraire.
