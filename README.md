# ETIMARKI PAMOJA HAKUNA MATATA — version premium

Cette version met à jour le site existant sans supprimer les 9 projets ni les médias fournis.

## Fonctionnalités

- Interface premium vert / blanc / sombre avec dégradés animés.
- Responsive mobile, tablette et desktop.
- SEO préparé (meta, Open Graph, structure sémantique, robots.txt) sans inventer de domaine de production.
- Français, English et Esperanto, avec Esperanto comme langue initiale.
- Chaque projet possède sa propre fiche et sa propre galerie d'images.
- Pas de galerie générale mélangeant les projets.
- Modal de case study avec navigation entre les images d'un seul projet.
- Filtres de projets.
- Animations reveal, hover et arrière-plan, avec prise en charge de `prefers-reduced-motion`.
- Navigation mobile.
- Sélecteur de langue.
- Formulaire de contact ouvrant la messagerie avec l'adresse officielle.
- Réseaux sociaux officiels.
- Partenaires issus des ressources du ZIP.
- Espace d'administration de démonstration conservé et amélioré.

## Lancer localement

Ouvrir `index.html` dans un navigateur moderne, ou lancer un serveur local depuis le dossier `etimarki_site`.

Pour production, connecter l'administration à une authentification et une base sécurisées (par exemple Supabase Auth + Database + Storage).
